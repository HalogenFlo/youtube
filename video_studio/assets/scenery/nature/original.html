Thư viện object thiên nhiên — Mỗi cây và mỗi con vật là một object riêng giống như nhân vật Lumi. Bấm vào một object trong cảnh, hoặc chọn trong danh sách bên dưới, rồi điều khiển riêng object đó. Bạn cũng có thể kéo thả object đi chỗ khác.
Có 18 object: 6 cây (thông, sồi, anh đào, cọ, tre, liễu) và 12 động vật (hươu, thỏ, cáo, sóc, cú mèo, rùa, vịt, cá, ếch, chim, bướm, ong). Mỗi object còn có một file SVG riêng trong thư mục objects để bạn lấy ra dùng lại ở cảnh khác, y như cách dùng object nhân vật Lumi.
